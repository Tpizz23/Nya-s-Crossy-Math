Replace the flat, automatically scrolling emoji game with a player-led 3D crossing adventure. The world now has modeled characters, raised terrain, shaded trees, traffic, floating logs and railway warning lights, plus smooth hopping, responsive touch/keyboard controls and pause.

Math checkpoints and collision recovery freeze the world while the learner answers. Recovery always returns to safe grass; scoring rewards only newly crossed rows. Existing operations, difficulties, the local save key and all 30 character unlock thresholds are preserved. The site remains statically hosted and includes its pinned graphics runtime locally.

Validation: model and math/save regression tests, syntax/local-asset checks, and desktop/mobile browser journeys covering correct and incorrect answers, game over, replay, pause, progression and character selection. Local screenshots cover desktop/mobile home and play plus the quiz overlay.

Greptile review is pending. No deployment included. WebGL is required; native Safari/Firefox and physical mobile devices have not been tested. Character unlocks use stylized block models rather than custom detailed assets.
